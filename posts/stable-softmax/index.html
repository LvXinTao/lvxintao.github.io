用 NumPy 实现数值稳定的 Softmax

Softmax 经常出现在分类模型和注意力机制中。它的定义很简单，但直接照着公式写代码，可能会遇到指数溢出。下面从这个问题出发，推导一个常用的稳定实现。

1. Softmax 在计算什么

给定一组实数分数 z1,z2,…,znz_1, z_2, \ldots, z_nz1​,z2​,…,zn​，Softmax 把它们转换成非负、总和为 1 的权重：

pi=ezi∑j=1nezjp_i = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}pi​=∑j=1n​ezj​ezi​​

指数函数保留分数的大小顺序：分数越大，得到的权重越大。分母再把它们归一化。

例如，对分数 [1, 2, 3]，输出约为：

输入分数Softmax 权重
10.0900
20.2447
30.6652

这些数值可以作为一个离散分布的参数；模型输出是否经过良好的概率校准，则是另一个需要评估的问题。

2. 为什么直接计算会出问题

最直接的 NumPy 写法是：

import numpy as np


def naive_softmax(x):
    exp_x = np.exp(x)
    return exp_x / exp_x.sum()

当输入是 [1000, 1001, 1002] 时，双精度浮点数无法表示这些指数值，np.exp() 会溢出为 inf。归一化时继续计算 inf / inf，结果就变成了 nan。

但观察两组输入：

  • [1, 2, 3]
  • [1000, 1001, 1002]

它们的相对差值完全相同，理应得到相同的 Softmax 输出。

平移不变性

给所有分数减去同一个常数 ccc：

ezi−c∑jezj−c=e−cezie−c∑jezj=ezi∑jezj\frac{e^{z_i-c}}{\sum_j e^{z_j-c}} = \frac{e^{-c}e^{z_i}}{e^{-c}\sum_j e^{z_j}} = \frac{e^{z_i}}{\sum_j e^{z_j}}∑j​ezj​−cezi​−c​=e−c∑j​ezj​e−cezi​​=∑j​ezj​ezi​​

因此，数学上有：

softmax⁡(z−c)=softmax⁡(z)\operatorname{softmax}(z-c)=\operatorname{softmax}(z)softmax(z−c)=softmax(z)

选择 c=max⁡jzjc = \max_j z_jc=maxj​zj​ 后，平移后的分数都不大于 0，最大的指数值恰好是 1。这样就避免了正向指数溢出。

关键是利用数学上的等价变换，让中间计算落在浮点数更容易表示的范围内。

3. 一个支持批处理的实现

下面的实现可以沿指定的 axis 归一化，并要求输入为非空、有限实数数组：

import numpy as np


def softmax(x, axis=-1):
    x = np.asarray(x, dtype=np.float64)

    if x.size == 0:
        raise ValueError("softmax requires a non-empty array")
    if not np.isfinite(x).all():
        raise ValueError("softmax requires finite input values")

    shifted = x - np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(shifted)
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)

这里有两个值得留意的细节：

  1. 使用 keepdims=True：保留被归约的维度，让广播运算仍然与原数组对齐。
  2. 按指定维度计算最大值与总和：对二维批次输入，axis=-1 会分别处理每一行。

这个示例显式拒绝 nan 和无穷值。如果要处理注意力中的掩码，还需要单独定义掩码规则，尤其是整行都被屏蔽时的行为。

4. 用几个性质检查实现

相比只看一组输出，更有用的检查是验证计算应满足的性质：

x = np.array([
    [1000.0, 1001.0, 1002.0],
    [-1000.0, -1000.0, -1000.0],
])

p = softmax(x, axis=-1)

# 每一行的概率总和应接近 1。
assert np.allclose(p.sum(axis=-1), 1.0)

# 概率应为非负值，计算结果应全部有限。
assert np.all(p >= 0)
assert np.isfinite(p).all()

# 给所有分数加上同一个常数，结果应保持一致。
assert np.allclose(p, softmax(x + 123.0, axis=-1))

# 相同分数对应均匀分布。
assert np.allclose(p[1], [1 / 3, 1 / 3, 1 / 3])

print(np.round(p, 4))

预期输出：

[[0.09   0.2447 0.6652]
 [0.3333 0.3333 0.3333]]

浮点数运算存在舍入误差，因此这里使用 np.allclose()，而不是逐个比较浮点数是否完全相等。

5. 稳定实现的边界

减去最大值解决了常见的正向指数溢出，但仍需理解它的边界：

情况需要关注的行为
分数之间的差距很大很小的指数值可能下溢到 0
输入含 nan 或无穷值需要显式定义或拒绝这类输入
批处理输入确保 axis 对应需要归一化的维度
后续需要对概率取对数极小概率可能先下溢为 0，宜直接使用稳定的 LogSoftmax
