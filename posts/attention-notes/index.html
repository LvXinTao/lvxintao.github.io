这是一个用于展示公式排版的概念示例。注意力机制可以理解为：根据当前问题，从一组信息中计算出不同的关注程度，再把这些信息加权组合起来。

一个加权汇总的过程

对于缩放点积注意力，常见的表达式是：

Attention⁡(Q,K,V)=softmax⁡(QK⊤dk)V\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)VAttention(Q,K,V)=softmax(dk​​QK⊤​)V

这里的 QQQ 是查询，KKK 是键，VVV 是值。dkd_kdk​ 表示键向量的维度。

可以分三步理解这段计算：

  1. 计算 QK⊤QK^\topQK⊤，衡量查询与不同键之间的匹配程度。
  2. 缩放后使用 softmax，把每个查询对应的分数转为归一化权重。
  3. 对 VVV 加权求和，得到聚合后的表示。

为什么要缩放

当向量各维分量满足一定的独立性和方差假设时，点积的方差会随维度增长。除以 dk\sqrt{d_k}dk​​ 有助于控制分数的尺度，避免 softmax 过早进入梯度很小的区域。

这是一种解释初始化附近数值行为的直觉，并不意味着训练中的表示始终满足这些假设。

用 NumPy 写一遍

下面的代码只展示核心计算，没有加入 mask、dropout 或批处理维度：

import numpy as np


def attention(q, k, v):
    scores = q @ k.T / np.sqrt(k.shape[-1])
    scores = scores - scores.max(axis=-1, keepdims=True)
    weights = np.exp(scores)
    weights = weights / weights.sum(axis=-1, keepdims=True)
    return weights @ v

减去每一行的最大值不会改变 softmax 的结果，但可以降低指数运算溢出的风险。
